Azure IoT Central: Quick Connect Workshop Series

Over my years at STMicroelectronics, I partnered with the Azure IoT team to design and deliver hands-on workshops for connecting STM32 microcontrollers to Azure IoT Central. These workshops empower engineers to quickly connect, configure, and stream real sensor data from STM32L4 and STM32U5 boards to the cloud.

My step-by-step guides and live demonstrations simplify the process, reducing software requirements and setup time. Participants learn to:

  • Set up a free Azure IoT Central Application
  • Add and configure devices using STM32 Discovery Kits
  • Collect connection credentials and configure Wi-Fi
  • Run Quick Connect scripts to publish sensor data
  • Monitor device activity in real time
These workshops showcase my ability to architect cloud-connected solutions, create clear instructional content, and teach advanced IoT concepts to a global audience. The accompanying videos and guides have helped hundreds of engineers accelerate their Azure IoT projects.
